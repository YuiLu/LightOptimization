## 口径

优化使用 Unity URP 原生 RGB。主排名采用三视角冻结 Signed Log 目标和逐视角能量权重。相机预算按实际渲染图数计，目标、机制诊断和独立验收另计。GT 只参与离线参数核验，未进入插件默认配置。

实跑环境：Unity 2022.3.62f3c1 / URP 14.0.12 / Direct3D 11 / NVIDIA GeForce GTX 1060 6GB（驱动 32.0.15.8278）。各批见 [环境指纹](render-environment.json)。
