# E26｜多视角停滞、局部约束、C3 GPU 与原生白光色温

E26 基于 [E25 `81fbfef`](https://github.com/YuiLu/LightOptimization/tree/81fbfef466efa021d997cdd5482cc557c13a31e3/docs/blackbox-e25)。所有优化目标和试探步均由 Unity 原生全场景 RGB 计算；GPU 仅融合 C3 的锚定图像列。灯具同时更新；没有外部渲染器、逐灯 GT 优化目标、深度代理或待优化相机。

## A｜多视角的诊断和在线提案

**动机。** Classroom 的 L6 在单视角可恢复，在三视角联合目标下卡住。固定同一初态和三个视角的归一化，区分梯度抵消、局部模型预测误差和合法性裁剪。

- 起点梯度抵消率约 **73.1%**，E25 V3 失败点仅约 **0.15%**（物理尺度约 **0.14%**），V0/V1 梯度余弦约 **−0.999998**。失败点全视角模型仍为 4/4 秩。各视角的 `Jᵀr` / `JᵀJ` 之和与全图构建一致；20 mm 失败点的三个视角之间有显著方向冲突。
- 在固定失败点，5/20/50 mm 下试过的联合、单视角、双视角与 Cauchy 步都未降低真实三视角 F；这些候选没有碰撞回退。20 mm 下联合二次模型预测的小幅下降没有兑现。因此，抵消和局部预测误差均有直接证据，步长的碰撞裁剪不是这个状态下的主要解释。这组有限方向审计不判定严格局部极小值。
- 单独拟合 **V02、V12** 可恢复 L6，**V01** 仍在约 **63.1 cm / 38.0%**；拟合 V02、V12 分别用 **360 / 200** 张图。与 E25 V0/V1/V2 各自恢复、V3/V5 均失败一起看，增加视角并不保证此目标下的当前局部优化变得容易。子集拟合是观测对照，不计为联合拟合成功。
- 在线单视角池触发了六次真实复拍（18 张图），全部拒绝。A0、A1 最终均约 **63.1 cm / 38.0%**；双视角池和七灯扩张均未满足启动条件。

## B｜逐灯位置回退与停滞恢复

**动机。** Complex Far 的 28D 联合拟合经常因某盏灯的碰撞而对全步缩放。逐灯回退能保留其他参数的提案，把约束造成的信号损失与联合问题的可辨识性分开。

| Complex Far / Off | 最终 F | 最差位置 / 强度 | 留出 Raw | 优化图数 | 通过 |
|---|---:|---:|---:|---:|---|
| B0 全步回退 | 0.02118 | 112.38 cm / 194.12% | 32.57% | 4,620 | 否 |
| B1 逐灯 XYZ 回退 | 0.01997 | 123.78 cm / 184.84% | 28.78% | 4,665 | 否 |

B0 的 46 个提案有 37 个统一缩步；B1 的 42 个提案没有全 rig 缩步。B1 保留其他灯的合法 XYZ 更新和所有 log(I) 更新，真实验收前按最终步重算预测。图像目标下降更多，但灯位误差扩大，仍未过线；因此 B1 的跨起点验证没有启动。低图像误差与正确恢复灯阵在此例是两件事。

### B2｜固定条件的停滞消融

S0 沿用 E25 的拒绝调度；S0-fixed 固定 20 mm，用来隔离 S1/Cauchy 与 S2/非单调本身的作用。非单调只在普通提案失败后启用，最多连续接受两步，使用最近五个已接受 F 的最大值与 `1.05 × best` 上限；返回值始终保留全局最佳合法状态。诊断 F 与求解用 F 的映射和目标一致。

| 固定场景 / 起点 | S0 | S0-fixed | S1 | S2 |
|---|---:|---:|---:|---:|
| Classroom L6，E25 V3 失败点 | 63.10 cm / 38.00% | 63.10 cm / 38.00% | 63.10 cm / 38.00% | 63.10 cm / 38.00% |
| Complex Far，七灯 Off | 112.38 cm / 194.12% | 112.38 cm / 194.12% | 112.38 cm / 194.12% | 112.38 cm / 194.12% |
| Classroom dir1301，七灯 Hard C3 | 8.05 cm / 14.44% | 8.05 cm / 14.48% | 8.05 cm / 14.48% | 8.05 cm / 14.48% |

L6 与 dir1301 的 Cauchy 候选均被拒绝。S2 分别接受了两步、三步在记录精度内持平的状态；L6 的末态 best 不变，dir1301 相对 S0-fixed 的 F 差约 `1.1×10⁻¹⁰`，没有参数恢复收益。Complex Far 的各臂在预算内仍能取得普通下降，额外分支未触发。三组均未过线；未组合这些模块，未执行可选随机扰动、Dogleg 或 L-BFGS。

固定端点还做了 [5/20/50 mm 原生差分复拍](stall-fd.csv)：Complex Far 的三个梯度方向余弦 ≥0.999，最佳 Cauchy 实降约 `3.0×10⁻⁴`，符合其被预算而非完全无下降截断的现象。Classroom 在归档 C3 失败点重建 **Hard H1** 时，5/50 mm 相对 20 mm 的梯度余弦约 0.66/0.24；20 mm 的 Cauchy 步使真 F 降约 0.00792。这是同一 F 上的另一种局部模型诊断，不等同于 C3 在线 S1。

## C｜通用参数布局与 C3 GPU

布局显式声明灯块、物理坐标与归一化、有限差分步长和信任半径。C3 GPU 只融合 XYZ 映射差分；原生探测、强度和 mired 的完整差分、Gram/求解及接受逻辑维持原路径。

固定同输入 C3 核对 **93/93** 通过（原生输入 21 项，1/2/3/5 视角的合成输入 72 项，含 central、两种单边、负值与 HDR）。非步长量相对 L2 门槛 `1e-4`（绝对下限 `1e-12`），步长余弦门槛 `0.9999`；最大相对 L2 **1.36×10⁻⁵**。CPU 直接列对照、完整四维重放和热身后 GPU 重复见下表。

| 4D CPU C3 起点 | E25 归档 C3 / C4 通过 | E26 兼容 / 显式布局通过 | E25 C3 → E26 优化图数 |
|---|:---:|:---:|---:|
| Complex dir911，20 cm | 是 / 是 | 是 / 是 | 3,756 → 3,579 |
| Complex dir1201，30 cm | 是 / 是 | 是 / 是 | 3,039 → 2,862 |
| Complex Seed509 Far | 是 / 是 | 是 / 是 | 4,632 → 4,323 |
| Classroom dir1301，10 cm | 否 / 否 | 否 / 否 | 3,159 → 2,793 |

E26 同环境、同起点的兼容/显式布局，列范数、Gram、梯度、物理步和终态均逐项相同，接受轨迹与实际图数也一致。和 **归档 E25** 跨批次相比，通过结论相同，但浮点轨迹和停止成本不同；历史轨迹不计为精确重放。同输入首模型的直接列核对为 **112/112**，相对 L2 容差 `1e-6`，实际误差为零。

## D｜原生白光色温

七盏灯滤镜固定白色，GT 色温预定为 `3000/4500/6500/3000/4500/6500/4500 K`，Range、灯型和曝光固定。启用 Unity 的原生色温及线性强度；抓到的 `VisibleLight.finalColor` 随温度改变。Hard 图集审计中，±40 mired 未改变七灯的图集布局。2500 和 9000 K 在合法方向分别实际执行二阶单边差分。

三个 GT 色温的 Hard / Off 原生温度列均可测，5 和 10 mired 的局部方向一致；匹配视角重复捕获的残差噪声为零（记录精度内）。三个 J4 加入温度列后均为有效秩 5，温度列相对现有四列空间的正交剩余占 **75.2–99.9%**，不是强度的简单重参数化。该结论限定于这些颜色、相机和状态。D1、D2 各 **6/6**，最大末态色温误差均低于 **0.001 mired**。

| 阶段与方法 | 通过 | 优化图数中位 | 结果 |
|---|:---:|---:|---|
| D3 Hard C3，单灯 5D / 对照 4D | 6/6 / 6/6 | 393 / 321 | 5D 最差留出 Raw 0.035%，最大温度误差 0.1013 mired；配对留出均在门槛内 |
| D3 Hard H1，单灯 5D | 4/6 | 549 | L1 两个起点分别停在 19.89 / 30.02 cm，留出 Raw 35.30% / 38.02% |
| D3 Off 完整 FD，单灯 5D / 对照 4D | 6/6 / 6/6 | 217.5 / 178.5 | 六个起点均恢复 |
| D4 Hard C3，双灯 10D / 对照 8D | 4/4 / 4/4 | 667.5 / 543 | 两类组的两个匹配起点均恢复 |

D3 是 L1/L3/L6 的两个冻结方向（各约 20/30 cm），位置、强度、温度一次联立；4D/8D 对照固定在 GT 温度。D4 在新白光 GT 重测全场景线性 RGB 对强度的响应，最低/最高相对耦合组分别为 **L6/L7** 和 **L5/L7**，Hard 响应的平方余弦约 `9.44×10⁻¹⁴` / `3.14×10⁻³`。这里的「高」是七灯内部相对排名。

## 口径与复现

- **环境与样本。** Unity 2022.3.62f3c1 / URP 14.0.12 / D3D11 / GTX 1060 6GB，线性色彩空间、Forward+、原生材质与阴影，Hard 图集上限 2048²。重放前校验场景资产、包与渲染设置清单、相机姿态、灯具属性和 E25 原始快照。新白光色温目标独立重拍；`raw-parameters.zip` 收录全精度参数、逐次查询姿态、冻结输入和环境清单，不含逐帧图像或渲染缓存。各阶段源码、输入及相机摘要见 [`stage-summary.json`](stage-summary.json)。
- **图像与目标。** 三视角 `0/1/2` 拟合，448×256；896×512 重拍同视角及独立留出 `3/4`。双视角拟合仅用于 A1 诊断。Signed Log 映射为 `sgn(x)·log1p(|x|/s)`，`s` 为对应冻结目标正 RGB 通道的 P90。`F = mean_v[sum_{p,c}(M(render)-M(target))² / (sum_{p,c}M(target)² + 1e-12)]`。RGB 三通道同权，不单独归一化。Raw/Log/Display NRMSE 先按视角计算 `sqrt(误差能量 / 目标能量)`（分母加 `1e-12`，Display 分母取 `max(目标能量, 1e-12)`），再对所列视角取 RMS。Display 使用固定 `1-exp(-max(0,x))` 再转 sRGB，曝光不拟合。
- **成本与门槛。** 主比较每臂最多 4,725 张实际拟合相机图；两视角受整数预算限制为 4,724。初始、双 anchor、所有 On/Off 探针、被拒绝及额外验收候选均计入；目标、固定点诊断和末态复拍另计。`model-checkpoints.csv` 记录完成第 4/8/16 次模型构建时已接受的 best（对应模型的下一次提案未计入），首次过线只做事后评分，不参与接受或停机。Pass 要求每个活动灯位置 ≤5 cm、强度相对误差 ≤5%、终态合法，D 系列另要求 ≤10 mired。阈值、扰动与条件门记录在运行脚本中。
- **配置。** H0 为 Raw Hard 完整 FD；H1 为 Signed Log Hard 完整 FD；C3 为 Signed Log Hard 目标 + Anchored Off 的 XYZ 列，log(I) 和 mired 使用原生 Hard 映射 FD；C4 加逐灯 mask，作为 E25 与 GPU 数值对照。Off 臂以匹配的关阴影目标做完整映射 FD。研究臂切换由原生 F 决定，GT、Oracle 终点及留出帧只作冻结或事后诊断。插件默认行为未改。
